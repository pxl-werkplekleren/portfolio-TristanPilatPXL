Portfolio Website

WPL1 HTML5 CSS3 JavaScript Responsive Design Git

Dit portfolio heb ik volledig zelf ontworpen en gebouwd zonder templates of externe frameworks. De site omvat meerdere pagina's met een consistente dark-themed lay-out, responsive design voor mobiel en desktop, en een volledige JavaScript-animatielaag: particle canvas, typing effect, scroll reveal, 3D card tilt, magnetic buttons en een custom cursor.

Ik bouwde het iteratief op: HTML/CSS structuur eerst, daarna verfijning van het design en tot slot de volledige JavaScript-animatielaag als afzonderlijk bestand. Elk onderdeel, van de IntersectionObserver voor scroll-animaties tot de requestAnimationFrame-loop voor het particle-systeem, heb ik zelf geschreven en geoptimaliseerd.

Wat ik leerde: Canvas API, IntersectionObserver, CSS custom properties, requestAnimationFrame-loops, responsive design patterns, toegankelijkheid (WCAG AA).

C# Console Applicatie

WPL1 C# .NET Visual Studio OOP

Voor deze opdracht bouwde ik een interactieve consoleapplicatie in C#. De applicatie verwerkt gebruikersinvoer via de terminal, past conditionele logica toe en geeft correcte uitvoer terug. Ik werkte met variabelen van verschillende datatypes, voorwaardelijke structuren (if/else, switch), iteraties (for, while) en zelfgedefinieerde methoden.

Na een eerste versie ontving ik feedback van de docent, die ik concreet heb verwerkt: ik verbeterde de naamgeving van variabelen, voegde validatie toe voor foutieve invoer en herstructureerde de logica in kleinere, herbruikbare methoden. De feedbackverwerking leerde mij hoe belangrijk het is om code te schrijven die anderen ook kunnen begrijpen.

Wat ik leerde: Datatypen en operators in C#, methoden schrijven, feedback verwerken, code structureren voor leesbaarheid.

C# WPF Applicatie

WPL1 C# WPF .NET XAML

Na de consoleapplicatie stapte ik over naar Windows Presentation Foundation (WPF) voor het bouwen van een grafische gebruikersinterface in C#. WPF was voor mij een volledig nieuwe technologie: ik leerde werken met XAML voor de opmaak van de interface en C# voor de achterliggende logica. De applicatie reageert op gebruikersinput via knoppen en invoervelden in een visuele omgeving.

WPF vereist een andere manier van denken dan een consoleapplicatie: de interface en de logica zijn gescheiden, evenementen (events) sturen de uitvoering en de gebruiker interageert via GUI-elementen in plaats van tekstinvoer. Om dit te leren heb ik naast de lessen extra tutorials gevolgd, wat mij hielp om de concepten sneller in de praktijk te brengen.

Wat ik leerde: XAML-opmaak, event-driven programming, scheiding van interface en logica, zelfstandig een nieuwe technologie aanleren.

Scratch Ballonspel

WPL1 Scratch Game Logic Visueel Programmeren

Dit was mijn eerste programmeerproject: een ballonspel in Scratch waarbij de speler objecten moet ontwijken. Ik heb de basisopdracht voltooid (een speler die beweegt en objecten die vallen) en daarbovenop extra functionaliteiten toegevoegd: meerdere levels met toenemende moeilijkheid en een puntensysteem dat de score bijhoudt.

Als eerste kennismaking met programmeerlogica leerde dit project mij de fundamentele concepten: variabelen (voor score en levens), condities (botsingsdetectie), iteraties (herhalende beweging) en events (wanneer start, wanneer einde). Dat ik initiatief nam om extra features toe te voegen, toont mijn motivatie om verder te gaan dan de minimumvereisten.

Wat ik leerde: Programmeerlogica (variabelen, condities, events), game loop, botsingsdetectie, iteratief bouwen en verfijnen.

Curriculum Vitae in HTML/CSS

WPL1 HTML5 CSS3 Lay-out

Voor deze opdracht bouwde ik mijn eigen curriculum vitae als een webpagina in HTML en CSS. Het CV bevat persoonlijke gegevens, een overzicht van mijn opleiding en vaardigheden, en een professionele lay-out die afgedrukt kan worden.

Webpagina Recreatie

WPL1 HTML5 CSS3 Pixel-perfect

Voor deze opdracht moest ik een bestaande webpagina zo nauwkeurig mogelijk nabootsen in HTML en CSS. Het doel was om te leren hoe je een visueel ontwerp omzet naar werkende code, zonder te kopiëren maar door het zelf te analyseren en te reconstrueren.

Deze oefening leerde mij om een bestaande interface te "lezen": welke lay-outpatronen zijn gebruikt, hoe zijn kleuren, fonts en afstanden toegepast, en welke HTML-structuur past het best bij het visuele resultaat. Het verfijnde mijn oog voor detail en mijn vaardigheid om HTML/CSS-code te schrijven die een gewenst visueel resultaat oplevert.

Wat ik leerde: Interface analyseren en nabootsen, werken met fonts en kleurpaletten, precisie en aandacht voor detail in CSS.

NUnit Testen

WPL2 NUnit C# .NET Unit Testing

Tijdens WPL2 leerde ik hoe ik NUnit gebruik om geautomatiseerde testen te schrijven voor backend code. Testen hoeven niet complex te zijn: zelfs eenvoudige unit tests helpen om fouten vroeg op te sporen en de kwaliteit van het project te bewaren. Via NUnit schrijf je testmethodes die automatisch controleren of je code het verwachte resultaat teruggeeft.

Een concreet voordeel was de snelle feedback: als een collega code aanpast en een test plots faalt, zie je onmiddellijk welke functionaliteit gebroken is. Dat vermijdt regressiefouten in een teamproject. Ik schreef testen voor de backend-logica van ons Pop & Clay-project en leerde zo hoe testdekking het vertrouwen in een codebase verhoogt.

Wat ik leerde: NUnit teststructuur (Arrange/Act/Assert), unit tests schrijven voor C# methoden, regressiefouten detecteren, kwaliteitsbewaking in teamverband.

Statistieken met Chart.js

WPL2 JavaScript Chart.js HTML5 CSS3

Voor deze opdracht visualiseerde ik data over loyale klanten en kortingen aan de hand van interactieve grafieken. Via de Chart.js-library worden datasets omgezet naar overzichtelijke charts die direct in de browser draaien.

Dit project leerde mij hoe je een externe JavaScript-library integreert en configureert: van het inladen via een CDN tot het opbouwen van chart-objecten met eigen datasets, kleuren en labels. Het resultaat is een visuele weergave van statistieken die makkelijk te lezen en te interpreteren is.

Wat ik leerde: Chart.js integreren en configureren, data visualiseren met grafieken, werken met een externe JavaScript-library.

C# MAUI Android App

WPL2 MAUI C# Android DevTunnels Swagger SQL

In dit project verkenden we .NET MAUI om een C#-applicatie te bouwen die draait op Android. We leerden hoe je een Android-emulator opzet om de app te testen zonder fysiek toestel, en hoe je de app verbindt met een backend via een REST API. De app is gekoppeld aan een databank die data ophaalt en wegschrijft.

Een belangrijk onderdeel was het gebruik van DevTunnels: daarmee stel je een lokale backend tijdelijk bloot aan het internet zodat de Android-emulator (of een echt toestel) de API kan bereiken. Via Swagger konden we de API-endpoints documenteren en testen tijdens de ontwikkeling. Dit project gaf mij een eerste concrete ervaring met cross-platform mobile development.

Wat ik leerde: .NET MAUI projectstructuur, Android-emulator opzetten, DevTunnels gebruiken voor lokale API-toegang, Swagger voor API-documentatie, database-integratie in een mobiele app.
